# 简体中文发行版说明

本分支以 Frappe Learning 为唯一教学入口，不另建第二套管理后台。课程、班级、学员、作业、测验、编程练习和系统设置均继续使用 Learning 原有页面与权限模型。

## 本轮汉化范围

- 应用名称统一显示为“教学平台”。
- 新安装站点默认语言设为简体中文（`zh`）。
- 新安装站点启用 Frappe 原生手机号登录开关。
- 将 Learning 教学语境中的 `Batch` 统一翻译为“班级”，不再显示“批次”。
- 修订工作台中“快速开始”“基础数据”等不准确译文。
- 补齐 213 条核心页面译文，覆盖课程、班级、成员/学员、课时、作业、测验、编程练习、考核、进度和常用错误提示。

官方语言包仍有部分低频英文，主要集中在支付、招聘、第三方会议、初始化问卷和邮件模板。后续补译时应优先保持以下术语：

| English | 简体中文 |
| --- | --- |
| Learning / Frappe Learning | 教学平台 |
| Course | 课程 |
| Batch | 班级 |
| Member | 成员 |
| Student / Learner | 学员 |
| Lesson | 课时 |
| Assignment | 作业 |
| Quiz | 测验 |
| Programming Exercise | 编程练习 |
| Evaluation | 考核 |
| Enrollment | 报名 / 加入（按上下文） |

## 已有站点启用中文

`after_install` 只在首次安装应用时执行。已有站点切换到本分支后，需要在 Frappe 后台完成以下设置，然后清缓存并重新构建前端资源：

1. “系统设置”中将语言设为“简体中文”。
2. 启用“允许使用手机号码登录”。
3. “网站设置”中将网站语言设为“简体中文”。
4. 确保每个需要手机号登录的用户填写唯一的手机号。

手机号登录沿用 Frappe 原生认证：登录页面的账号输入框可填写手机号，密码仍为该用户密码。本分支不复制认证逻辑。
