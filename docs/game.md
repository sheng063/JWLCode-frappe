# Game 模块

入口：LMS 侧栏的 **Game**（默认路径 `/lms/game`）；手机端在“你”的学习功能列表中进入。

## 教师使用

1. 打开 Game，勾选或取消“向学生显示 Game 模块”。开关对全站学生生效，默认关闭。
2. 选择 HTML 文件或 ZIP 游戏包，可填写游戏名称；不填则使用文件名。
3. 点击“上传游戏”。成功后游戏出现在列表中。
4. 点击游戏卡片，跳转到独立游戏页面（`/lms/game/<游戏 ID>`）；支持重新开始和返回游戏列表，也可以刷新或直接打开游戏链接。

Course Creator、Moderator、System Manager 和 Administrator 可以管理游戏。关闭学生访问后，教师仍能查看、上传和运行游戏。学生只能在开放期间浏览、运行游戏，不能上传或更改开关；访客不能访问。

## HTML 文件要求

- 单个 `.html` 或 `.htm` 文件，UTF-8 编码，最大 5 MB。
- 脚本、样式、图片等建议内嵌；支持通过 HTTPS 引入脚本、样式、图片、字体和媒体。
- 直接上传 HTML 时不会上传同目录的其他文件；多文件游戏请将 HTML 和资源一起打包为 ZIP。
- 游戏在隔离 iframe 中运行，允许 JavaScript 和指针锁定。无法访问 LMS 页面、Cookie 或同源存储；单 HTML 游戏禁止网络 API 请求、表单提交和嵌套页面。ZIP 游戏允许加载包内资源、子页面及通过 fetch 读取包内数据；依赖 localStorage、IndexedDB 或外部后端接口的游戏需要调整，或另行配置独立游戏站点。

## 权限与存储

HTML 以 Base64 数据保存到 `LMS Game`，不会生成可直接执行的站内公开 HTML 文件地址。读取游戏列表和内容时，服务端检查登录状态与 `LMS Settings.game_enabled`。学生也不能通过通用 DocType REST 接口读取内容。

开关保存后发送实时通知，更新在线客户端菜单；学生正在运行的游戏会随关闭通知移除。Game 页面另每 30 秒检查访问状态，刷新按钮可立即重新检查。已经传给浏览器的游戏内容无法被远程收回。

## 2026-09-28：封面卡片与教师管理

- 卡片默认显示渐变背景。教师点击卡片下方的“编辑”，可修改游戏名称、简介和封面。
- 封面支持 JPG、PNG、WebP，最大 2 MB、1600 万像素；上传前可预览，也可恢复默认背景。服务端验证图片并重新编码为压缩 JPEG，最长宽高限制为 960 × 600，随游戏保存，无额外公开文件。
- 名称最多 140 字符，简介最多 500 字符；只改名称或简介时保留已有封面。
- “下载”保存上传的 HTML 游戏文件；修改展示名称不会改写下载文件名。
- “删除”需要确认，删除后无法恢复。学生和访客无法调用编辑、下载、删除接口。

本地站点已同步字段和界面。54 项前端测试、7 项数据库测试及生产构建通过；真实浏览器验证上传、名称/简介/封面编辑、刷新后保存结果、HTML 下载内容一致、手机布局、恢复默认封面、取消和确认删除通过。验收创建的游戏已删除，原有游戏保留。

## ZIP HTML 游戏包

- 上传支持 `.zip`，最大 20 MB；解压后总大小不超过 100 MB，单个资源不超过 20 MB，最多 1000 个文件/目录条目。
- 优先识别最外层的 `index.html` 或 `index.htm`，允许有一层或多层外层目录。如果没有 index 文件，但仅有一个 HTML 文件，则使用该文件。多个入口无法判断时，请在 ZIP 根目录放一个 `index.html`。
- 保持原文件结构，HTML 中使用相对路径引用 JS、CSS、图片、音视频、字体和数据文件。支持 JavaScript 模块和包内 JSON/fetch 请求；不依赖 ZIP 内的服务端程序。
- HTML 入口使用 UTF-8 编码。加密包、符号链接、重复或越界路径、非标准压缩方式会被拒绝。
- 点击卡片仍进入独立游戏页；名称、封面、简介编辑方式不变。下载会返回原 ZIP，删除会同步清理解压资源。
- 资源放在站点 `private/lms-game-packages`，通过有效期 8 小时的资源地址访问；每次请求检查游戏是否存在、用户是否启用以及学生访问开关。页面始终在隔离环境中运行，直接打开资源地址也会强制隔离。地址过期时重新加载游戏即可。
- 备份/迁移站点需要包含数据库和 `private/lms-game-packages`。其他站点部署时运行迁移、更新前端并重启应用以加载新增资源路由。

验证：56 项前端测试、13 项后端测试通过；真实浏览器验证 ZIP 上传、嵌套 HTML 入口、CSS、图片、普通脚本、模块导入、JSON/fetch、脚本隔离、页面刷新和原 ZIP 下载通过。原有单 HTML 游戏兼容。
