# 编程题编辑与隐藏用例管理

点击题目标题进入编辑页面，可修改标题、题目描述和公开例题。导入的 TeX 题面使用源码编辑及公式预览，保存会更新保留的题包源码及判题版本。PDF 题目的文字描述可编辑，原 PDF 可通过上传题包替换。

隐藏用例默认折叠，展开时读取预览；每个字段最多预览 2000 字符。下载按钮导出全部隐藏用例，ZIP 内为 `data/secret/001.in`、`001.ans` 等配对文件。上传支持配对的 `.in` / `.ans` 文件 ZIP，成功后立即替换全部隐藏用例，不需要额外点击保存。上传失败不会删除现有用例。

Delete 左侧的“上传题目”打开 ICPC 导入界面，上传目标固定为当前题目，发布后保留内部 ID 和题号。列表页的独立导入入口沿用原有新增逻辑。

ICPC 编辑和隐藏用例替换会发布新版本，历史提交仍引用原版本。服务端检查写权限和修改时间，避免旧页面覆盖他人的更新。ZIP 沿用现有容量和路径检查，发布沿用判题服务能力检查。

验证：38 项前端回归测试、7 项服务端归档与站点集成测试、前端 Vite 构建通过。站点测试使用临时题目并回滚，构建产物保存在临时目录，未部署到运行中的站点。
