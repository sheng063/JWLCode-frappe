# 视频选项导出失败修复（2026-09-27）

真实 HTTP POST `start_export` 返回 417：`include_videos` 缺少类型注解。LMS 启用了 Frappe 强制接口类型检查；此前直接调用函数的单元测试没有进入 HTTP 校验层，因此两种视频选项都漏测了同一个错误。

修复：给 `start_export` 的 `include_videos` 补充 `bool` 注解，默认值保持 `True`。已将该文件同步至本地 school.localhost 服务，真实 HTTP 请求确认生效。新增强制参数校验回归，覆盖字符串 0/1、布尔值及默认调用。导出相关 16 项后端测试通过。
