# 含视频大课程导出修复（2026-09-27）

已部署到本地 `school.localhost:8000`。

## 原因与修复

- 前端原先用 `response.blob()` 接收整个 ZIP，数十 GB 课程需要先完整缓存才触发下载。改为后台打包、查询状态，再使用浏览器原生下载。
- 原清理代码把队列执行超时当成延迟执行，可能在打包后立即删除文件。改为专用私有目录保存，按文件年龄每小时清理超过 24 小时的导出。
- 打包写入同目录的 `.partial` 文件，完成后原子改名；异常时删除未完成文件，避免跨文件系统再复制整包。
- 下载使用流式响应，支持 HTTP Range；启动、状态查询和下载均检查权限，任务限定发起用户。任务状态在普通站点清缓存后仍保留。
- 页面提供中文准备、完成和失败提示，重复点击不会重复排队；任务完成后再次导出会重新读取课程。
