# LMS 测验更新（2026-09-27）

已更新本地 `http://localhost:8000/lms/quizzes`。

## 使用

- 编辑测验，新增题目，在“类型”中选择“排序题”或“连线题”。
- 排序题：按正确顺序填写 2–20 个条目；作答时打乱，支持拖拽和上下移动按钮，完整顺序正确才得分。
- 连线题：每行填写一对内容，左右各列分别打乱。可以先点左侧或先点右侧；正确配对消失，错误显示提示，全部匹配即通过。
- 题干、选项、解析及客观题成绩详情以纯文本显示，处理旧内容中的 HTML 和转义 HTML，保留换行及 C++ 的尖括号。题干编辑改为文本框。历史题库和提交记录未做批量覆盖。

## 实现

`LMS Question.interactive_items` 保存条目及独立随机标识。服务端向学生返回打乱后的展示条目，不返回标准顺序或左右对应关系；配对接口检查测验访问权限，最终提交重新在服务端判分。修改共享题目类型会同步到测验题目行。

部署到其他环境时运行常规 `bench --site <site> migrate` 并重新构建前端；本地已加载两个相关 DocType 并更新构建产物。

- 38 项前端测试通过：原测验组件、题目编辑、计时与提交回归，以及新增的纯文本、排序和配对测试。
- 4 项真实数据库集成测试通过：排序判分、配对判分与权限、编辑校验、服务端题型判定。测试数据全部回滚。
