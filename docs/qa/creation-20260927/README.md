# LMS 创作模块

## 功能

- 登录用户侧边栏增加「创作」和「我的作品」，移动端可从个人导航进入。
- `/lms/create` 提供独立 Python/C++ 编辑器、自定义标准输入、运行结果与保存按钮。
- `/lms/my-creations` 按更新时间列出本人的作品，支持按名称搜索和分页。
- 保存代码、语言、作品名称与标准输入，重新打开可继续编辑。
- 离开未保存页面会提醒；多窗口编辑时拒绝覆盖已更新的作品。
- 运行复用 LMS Judge Settings 指定的隔离运行服务，不创建课程提交记录。
- 新增 LMS Creation DocType；通用文档接口无读写权限，专用接口校验登录状态和 owner。

## 部署

发布代码后，在目标 bench 执行：

```sh
bench --site <site> migrate
bench build --app lms
bench --site <site> clear-cache
bench restart
```

运行功能需要配置并启用 LMS Judge Settings；保存与读取作品不依赖运行服务。此次仅修改仓库并在本地容器验证，未部署线上站点。
