# 编程练习单题和批量导入

页面 `/lms/programming-exercises` 右上角依次为「导入」「批量导入」「查看所有提交」「创建」。

## 单题导入

「导入」打开独立 ICPC 导入窗口，上传一个 `.zip` 或 `.kpp` 标准题包，后台检查完成后选择 PDF 题面、语言、时间和内存限制，确认草稿并发布题目。不会进入手工创建表单。既有编辑表单仍可导入新版本。

## 批量导入

上传与批量导出相同格式的 ZIP 合集：外层 ZIP 根目录放置每道题的独立 `.zip`/`.kpp`，可以附带 `manifest.json` 和 `README.txt`。

- 支持最多 50 道题、合集最多 100 MiB、每题最多 20 MiB；同时受站点自身上传大小上限约束。
- 有导出清单时核对每题 SHA-256，并恢复语言、时间、内存设置供用户确认。没有清单也可导入，时间需手动填写。包内声明的内存限制优先。
- 点击「导入已就绪题目」逐题确认并发布，显示成功数量和各题错误。成功题目不重复导入，失败题目保留草稿，可重试发布。
- 导入不使用清单中的原题 ID 覆盖既有题目。沿用单题服务的去重规则：同一用户导入字节相同的题包，且执行配置和题面选择相同，会复用已有题目版本。
- 同一上传文件的后台重试会复用已有子文件和导入记录，避免重复草稿。

后台入口 `POST lms.lms.problem_package.bulk_import.create_bulk_import` 接收私有文件 ID，检查当前用户创建题目权限和上传文件所有权。只展开一层合集；每个子题包走已有异步预检和发布权限流程。拒绝路径穿越、重复或大小写冲突路径、未知附带文件、不匹配的清单摘要和超限归档。不会执行包内程序。

## 本地部署与验证（2026-09-07）

- 本地 `school.localhost` 已同步前后端代码、中文翻译，并开启 `enable_icpc_problem_packages`。
- 经用户授权升级本地判题适配器，启用 `ICPC_ENABLED`。保留旧镜像标签 `jwlcode-judge-service:before-icpc-import-20260907`，数据库和 Judge0 节点保留。
- 判题服务 31 项回归、比较器验证指纹检查、7 项真实 Judge0 执行测试通过。
- 批量导入后端 6 项测试通过；前端单题、批量流程及页面入口 7 项测试通过（使用兼容的隔离 Vite 7 / Vitest 4 环境）。
- 真实数据库验证导出两题合集后重新导入、复用重复请求、正常创建或复用题目而不覆盖原题。
- 真实浏览器验证右上角按钮顺序，单题上传→预检→草稿→发布、两题批量上传→预检→全部发布，以及手机宽度不溢出；测试题、版本、导入记录和私有文件均已清理。

当前本地判题节点的最低内存限制为 1024000 KiB，低于该限制的包无法发布，系统不会擅自改写题包限制。完整规范程序执行验证不在导入范围内。
