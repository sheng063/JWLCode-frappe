# 课程可见性、班级注册与讲师仪表盘

课程设置 → 可见性中新增“公开”（`is_public`）。公开且已发布的课程对所有学生可见；非公开课程仅对已注册的学生可见。讲师与管理员保留原有的管理能力。已有课程默认保持公开，避免升级时改变现有可见性；可按课程关闭此开关。

非公开课程的限制在服务端执行，覆盖课程列表、首页推荐、分类、详情、大纲、课时预览及班级课程展示。学生不能通过自助注册非公开课程，或修改已有注册记录中的课程、学生和班级来源来绕过限制。公开性与付费、自助学习、课时顺序等既有规则分别生效；公开不会自动授予付费课程的学习资格。

## 班级注册

- 学生加入班级后自动注册该班级的课程，包括非公开课程和禁止自助学习的课程。
- 班级新增课程时，为当前学生注册；移除课程、学生或班级时，回收该班级产生的注册。
- 同一学生在多个班级学习同一课程时，只保留一条课程注册。移除其中一个来源时，如果还有其他班级提供此课程，将来源转交给其他班级，保留注册记录和进度。
- 独立注册（非班级产生）的课程注册，不因退出班级而删除。
- 升级补丁 `lms.patches.v2_0.sync_batch_course_enrollments` 补齐历史缺失注册并清理失效的班级来源，可重复执行。

## Classes 编辑

讲师在 Classes 卡片上选择“编辑”，可更新标题、描述、日期、时间、时长、时区和录制设置。保存更新已有课堂、关联日历事件及 Zoom 会议，不会新建一个会议；Google Meet 继续通过关联日历事件同步。并发修改会提示重新加载，学生不能调用编辑接口。会议 API 失败会反馈错误。

## 仪表盘统计

在“学员加入时间”右侧增加：

1. **全部课程完成度**：班级内去重课程的完成度算术平均值，未开始或未注册的课程按 0% 计。
2. **编程题通过率**：该学生曾通过的去重编程题数量 ÷ 班级所有课程中去重编程题总量。同题重复提交、重复引用不重复计数；无编程题时显示 0%。

统计仅允许该班级讲师或管理员查看。请求只返回该班级学员的数据，分批加载，并忽略已经过期的异步结果。

## 升级与验证

更新代码后执行站点 `bench --site <site> migrate`、编译翻译、构建前端并重启服务。仓库的 `docker/redeploy.sh` 提供本地容器部署流程。

新增数据库测试：

- `lms.tests.test_course_visibility_and_batches`
- `lms.tests.test_live_class_edit`

前端测试覆盖课程公开开关、Classes 新增/编辑/返回路由、仪表盘列顺序、统计显示和请求竞态。
