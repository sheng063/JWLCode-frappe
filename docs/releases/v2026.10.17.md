# JWLCode v2026.10.17

首次按日期发布的 JWLCode 中文发行包；上游 LMS 应用版本仍为 2.45.2。

- 包含课程、班级、编程练习、ICPC 题包与课程迁移功能。
- 包含静态游戏上传、访问与解锁控制、通用 Colyseus 联机服务和前端 SDK。
- 默认开发分支统一为 main，更新中文 README 与发行包使用说明。
- 提供内容一致的 tar.gz / zip 源码包和 SHA256SUMS；保留完整运行源码、静态资源和许可证。
- 不包含 Git 历史、node_modules、Frappe UI 子模块、转换工作数据、Cypress 端到端测试及 QA 日志截图。完整开发和历史验收材料请克隆仓库。

使用步骤见发行包内 README 的“Release 下载与使用”：校验、解压、初始化本地 Git 后通过 Docker Compose 启动。包内未包含预构建前端、数据库、账号、站点数据、Docker 镜像和外部依赖；首次安装仍需联网构建。游戏联机服务需按 README 单独启用，判题服务独立部署。

Docker Compose 面向本地开发和验收。本次发布验证源码打包、两种归档内容和校验和；未对全新机器重新执行完整站点安装。
