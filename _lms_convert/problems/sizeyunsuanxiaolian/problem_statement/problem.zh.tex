\problemname{四则运算小练}

\subsection*{题目描述}
声明两个 int 类型的变量 a 和 b，分别存储来自输入的两个整数值。之后计算并输出 a + b、a − b、a * b、a / b 的结果，每个运算结果之间用一个空格隔开。注意：在 C++ 中，两个整数做除法时，结果也是整数，小数部分会被丢弃。

\subsection*{输入格式}
输入只有一行，包含两个用空格隔开的整数 a 和 b（0 < a < 100，0 < b < 100）。

\subsection*{输出格式}
输出一行，依次为 a + b、a − b、a * b、a / b 四个整数结果，之间用一个空格隔开。

\subsection*{样例输入}
\begin{verbatim}
3 2
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
5 1 6 1
\end{verbatim}
