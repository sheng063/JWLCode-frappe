\problemname{固定差值判断}

我们依次输入 $5$ 个数字，你需要判断所有相邻的两个数字之间的差值是不是一个固定的值？

\begin{itemize}
  \item 如果是，则输出\texttt{YES}；

  \item 如果不是，则输出：\texttt{NO}。

\end{itemize}
规定：相邻的两个数计算差值时，只能让后面的数减前面的数。

举例：如果输入 \texttt{1 2 3 4 5}，我们可以计算出：

\begin{itemize}
  \item $2-1=1$；

  \item $3-2=1$；

  \item $4-3=1$；

  \item $5-4=1$ ;

\end{itemize}
所有相邻的两个数的差值均为 $1$，则输出 \texttt{YES}。

\subsection*{输入格式}
输入一行由空格所隔开的五个小于 $10000$ 的正整数，且这五个整数依次增大。

\subsection*{输出格式}
\begin{itemize}
  \item 如果是固定的差值，则输出\texttt{YES}；

  \item 如果不是，则输出：\texttt{NO}。

\end{itemize}
\subsection*{样例输入}
\begin{verbatim}
1 2 3 4 5
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
YES
\end{verbatim}

\subsection*{样例 2 输入}
\begin{verbatim}
1 3 5 8 10
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
NO
\end{verbatim}
