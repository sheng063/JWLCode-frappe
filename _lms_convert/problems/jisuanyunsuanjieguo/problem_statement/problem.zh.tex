\problemname{计算运算结果}

\subsection*{题目描述}
使用 \texttt{cout} 输出算术表达式 \texttt{3 + 4} 的计算结果，并在输出结果前先把式子输出出来。

\subsection*{输入格式}
无。程序不需要读取任何输入。

\subsection*{输出格式}
输出字符串 \texttt{3 + 4 = } 后紧接着输出 \texttt{3 + 4} 的计算结果 \texttt{7}。

\subsection*{样例输入}
\begin{verbatim}

\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
3 + 4 = 7
\end{verbatim}
