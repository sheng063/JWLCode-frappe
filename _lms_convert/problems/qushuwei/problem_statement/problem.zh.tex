\problemname{取数位}

\subsection*{题目描述}
请灵活运用整除运算与取模运算，将输入给出的一个两位数分解为十位与个位，分别在两行输出。获取一个两位数的十位：整数除以 10；获取个位：整数对 10 取模。

\subsection*{输入格式}
输入只有一个整数 n，是一个两位数（10 ≤ n ≤ 99）。

\subsection*{输出格式}
两行，第一行输出 n 的十位数字，第二行输出 n 的个位数字。

\subsection*{样例输入}
\begin{verbatim}
32
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
3
2
\end{verbatim}
