\problemname{试一试逻辑运算}

\subsection*{题目描述}
输入四个整数 a、b、x、y，在两个关系表达式 a > b 与 x < y 上验证逻辑运算（且、或、非）的结果。布尔真输出 1，布尔假输出 0。

\subsection*{输入格式}
一行四个整数 a、b、x、y，用空格分隔，满足 -2^31 ≤ a, b, x, y ≤ 2^31 - 1。

\subsection*{输出格式}
共三行，每行数值之间以一个空格分隔：第一行为 (a > b)、(x < y)、((a > b) 且 (x < y))；第二行为 (a > b)、(x < y)、((a > b) 或 (x < y))；第三行为 !(a > b)、(x < y) 的取非 !(x < y)。

\subsection*{样例输入}
\begin{verbatim}
5 3 2 4
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
1 1 1
1 1 1
0 0
\end{verbatim}
