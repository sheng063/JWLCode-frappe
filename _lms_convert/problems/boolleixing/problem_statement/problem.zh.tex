\problemname{bool 类型}

\subsection*{题目描述}
验证 bool 类型变量的逻辑值，以及逻辑非运算符 ! 作用于 bool 类型变量后取值的变化情况。bool 变量可以被赋予逻辑值 true 或 false，其中 true 的值为 1，false 的值为 0。

\subsection*{输入格式}
本题没有输入。

\subsection*{输出格式}
输出两行。第一行输出 bool 变量赋值为 false 时的值（即 0）；第二行输出对该变量取逻辑非运算后得到的值（即 1）。

\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
0
1
\end{verbatim}
