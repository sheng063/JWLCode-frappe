\problemname{半价票问题}

\subsection*{题目描述}
火车站售票规则为：身高 1.2 米以下随父母出行免票，1.2 米至 1.5 米半价票，超过 1.5 米全票。给出身高 n，判断是否可以半价购票。

\subsection*{输入格式}
一个浮点数 n，表示身高，满足 0.5 ≤ n ≤ 3.0。

\subsection*{输出格式}
一行字符串：若 1.2 ≤ n ≤ 1.5，输出 YES，否则输出 NO，不需要换行。

\subsection*{样例输入}
\begin{verbatim}
1.3
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
YES
\end{verbatim}
