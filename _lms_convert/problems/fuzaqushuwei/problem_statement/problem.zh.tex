\problemname{复杂取数位}

请灵活运用整除运算与取模运算，将输入给出的一个三位数，分解为百位、十位与个位，分别在三行输出。

例如，对于输入 \texttt{321}，我们希望输出

\begin{verbatim}
3
2
1
\end{verbatim}

提示：

\begin{itemize}
  \item 获得百位：对给定整数直接除以整数 $100$

  \item 获得十位：有两种方式可供选择

\begin{enumerate}
  \item 对给定整数先除以 $10$ 再模 $10$

  \item 对给定整数先模 $100$ 再除以整数 $10$

\end{itemize}
  \item 获得个位：对给定整数模 $10$

\end{itemize}
\subsection*{输入格式}
输入为一行，包含一个整数 $n$（ $100\len\le999$ ）。

\subsection*{输出格式}
输出为三行，每行包含一个一位数，分别对应原来三位数的百位、十位和个位。

\subsection*{样例输入}
\begin{verbatim}
100
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
1
0
0
\end{verbatim}

\subsection*{样例 2 输入}
\begin{verbatim}
240
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
2
4
0
\end{verbatim}
