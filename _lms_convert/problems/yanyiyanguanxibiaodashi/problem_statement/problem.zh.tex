\problemname{验一验关系表达式}

\subsection*{题目描述}
输入两个整数 a 和 b，检验关系运算的结果值。依次输出判断 a 和 b 是否相等（a == b）以及是否不相等（a != b）的结果，布尔真输出 1，布尔假输出 0。

\subsection*{输入格式}
一行两个整数 a 和 b，用空格分隔，满足 -2^31 ≤ a, b ≤ 2^31 - 1。

\subsection*{输出格式}
共两行，每行一个 0 或 1：第一行为 a 和 b 是否相等的结果，第二行为 a 和 b 是否不相等的结果。

\subsection*{样例输入}
\begin{verbatim}
5 5
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
1
0
\end{verbatim}
