\problemname{考试等级划分}

\subsection*{题目描述}
给定一个百分制成绩 fen，根据成绩输出其对应的等级：90 分及以上为 A，80～89 分为 B，70～79 分为 C，70 分以下为 D。

\subsection*{输入格式}
一个整数 fen，表示百分制成绩，满足 0 ≤ fen ≤ 100。

\subsection*{输出格式}
一行一个字母：A、B、C 或 D（输出后换行）。

\subsection*{样例输入}
\begin{verbatim}
95
\end{verbatim}

\subsection*{样例输出}
\begin{verbatim}
A
\end{verbatim}
